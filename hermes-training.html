🎯 Introduction à Hermes

Qu'est-ce que Hermes ?

Hermes Agent est un framework d'agent autonome open-source créé par Nous Research. C'est un outil qui :

  • ✅ Comprend des instructions en langage naturel
  • ✅ Exécute des tâches complexes automatiquement (code, recherche, automation)
  • ✅ Fonctionne avec TOUS les modèles IA (Claude, GPT-4, DeepSeek, local, etc.)
  • ✅ Garde la trace de ce qu'il apprend (memory persistante)
  • ✅ Fonctionne sur tous les canaux (Discord, Slack, Telegram, CLI, Desktop, Web)
  • ✅ Peut être étendu avec des outils et des skills customisés

🔑 Différences avec Claude Pro

❌ Claude Pro (Abonnement)

  • Chat seulement
  • Dépendant d'Anthropic
  • Pas de memory persistante
  • Pas d'automation
  • Pas d'intégration tools
  • Coût fixe ($20/mois)

✅ Hermes Agent

  • Chat + automation + orchestration
  • Marche avec n'importe quel modèle IA
  • Memory persistante entre sessions
  • Automation complète (cron, webhooks)
  • 50+ outils natifs intégrés
  • Pay-per-token (plus cheap)

⚙️ Fonctionnalités Core

🧠

Memory Persistante

Hermes retient tes préférences, contexte, et lessons learned d'une session à l'autre. Zéro répétition — tu lui dis une fois, il le sait à jamais.

💾

Skills (Procédures Réutilisables)

Sauvegarde les workflows qu'il répète souvent comme "skills". Hermes les charge automatiquement dans ses futures sessions.

🔌

Multi-Providers

Utilise Claude, GPT-4, DeepSeek, xAI, Google, local GGUF, ou n'importe quel modèle. Swap mid-workflow sans perte de contexte.

📱

Multi-Platform Gateway

Même agent sur Discord, Slack, Telegram, WhatsApp, iMessage, Signal, Teams, Email. Avec accès complet aux tools.

🛠️

50+ Outils Natifs

Terminal, file system, GitHub, Figma, Airtable, Google Workspace, Composio, et des dizaines d'autres. Extensibles.

⏰

Cron & Webhooks

Automatise des jobs qui tournent on schedule. Reçois des événements externes et lance des agents automatiquement.

📂

Profiles Isolés

Crée plusieurs instances d'Hermes avec configs séparées. Exemple : 1 pour le travail, 1 pour perso, 1 par client.

🔐

Open Source & Self-Hosted

Code source public. Peux tourner 100% local, en Docker, sur Hermes Cloud. Tu gardes la donnée.

🤖

Multi-Agent Workflows

Spawne 5+ agents en parallèle qui collaborent. Exemple : Designer + Backend + Frontend + DevOps + QA livrens une app ensemble.

💬

MCP Servers

Intègre n'importe quel protocole MCP. Figma, GitHub, Airtable, Notion, Google Workspace, Composio, 50+ autres natifs.

📦 Profiles Isolés

Cas d'Usage : Agence Multi-Client

Chaque client = son propre profile avec :

  • Config séparée (modèle, tools, voice)
  • API keys séparées (GitHub token client-specific)
  • Memory isolée (zéro cross-contamination data)
  • Skills spécialisées
  • Cron jobs propres
# Créer et switcher $ hermes --profile client-acme $ hermes --profile client-bigcorp $ hermes --profile perso # Configurer individuellement $ hermes --profile work config set model.default gpt-4-turbo $ hermes --profile perso config set model.default claude-haiku

🤝 Multi-Agent Workflows

Cas d'Usage : Livrer une App Complète

Au lieu de : 1 agent qui code 20 jours (design → backend → frontend → ops → tests séquentiellement)

Fais : 5 agents en parallèle (Designer + Backend + Frontend + DevOps + QA en 4 jours)

Résultat : 5x plus vite, 10x moins cher

❓ FAQ

Est-ce que Hermes remplace Claude Pro ?

Partiellement. Si tu fais juste du chat, Claude Pro est simple et supporté. Mais si tu veux automation, multi-agents, cost optimization, ou multi-platform, Hermes est 10x mieux. Hermes peut d'ailleurs utiliser Claude comme modèle backend — c'est juste plus flexible.

Est-ce difficile à installer ?

Non ! Un seul script d'installation : curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash. Ça setup tout (Python venv, tools, launcher). Après, c'est juste hermes pour lancer.

Faut-il une API key pour chaque provider ?

Oui, mais c'est optionnel. Si tu veux utiliser Claude, ajoute ta clé Anthropic. Si tu veux GPT-4, ajoute OpenAI. Si tu veux local GGUF, zéro clé. Hermes peut tourner 100% gratuit avec des modèles open-source.

Comment créer une skill ?

Sauvegarde un workflow réussi : hermes skill create mon-workflow "Description". Hermes l'ajoute automatiquement à ses futures sessions. C'est comme une fonction réutilisable.

Peux-tu avoir plusieurs Hermes qui tournent simultanément ?

Oui ! Utilise des profiles : hermes --profile work & et hermes --profile perso &. Chacun tourne comme un process indépendant avec sa config, memory, et tools séparés.

Quel est le coût réel ?

Hermes est gratuit (open-source). Tu paies seulement l'API backend que tu utilises : Claude = $0.80/1M tokens input, GPT-4 = $0.03/1K tokens, DeepSeek = 0.14¢/1M tokens. Zéro abonnement obligatoire.

Est-ce que mes données sont sécurisées ?

Oui. Hermes tourne 100% local ou en Docker. Tes données ne vont jamais aux serveurs Nous Research. Tu contrôles tout (configs, memory, skills, logs). Si tu veux cloud, tu utilises Hermes Cloud (self-managed).

Puis-je intégrer mes outils spécifiques ?

Oui ! 3 façons : (1) MCP servers pour les protocoles standards, (2) Custom tools via Python, (3) Webhooks pour les événements externes. Hermes peut parler à n'importe quel API.
